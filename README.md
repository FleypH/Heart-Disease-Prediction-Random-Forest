# Heart Disease Prediction using Random Forest

## Overview
This project predicts the likelihood of heart disease using the Random Forest classification algorithm. It demonstrates the complete machine learning workflow, including data preprocessing, exploratory data analysis, model training, evaluation, and prediction.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Features
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Random Forest Classification
- Model evaluation
- Prediction of heart disease risk

## Skills Demonstrated
- Machine Learning
- Data Analysis
- Data Visualization
- Classification
- Feature Engineering
